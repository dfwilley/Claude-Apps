# Claude-Apps

Small web apps built with Claude, served with GitHub Pages.

- [Knot of the Day](https://dfwilley.github.io/Claude-Apps/knot-of-the-day/) — learn one sailor's knot at a time with step-by-step drawings.
- [Wire Bender](https://dfwilley.github.io/Claude-Apps/wire-bender/) — draw a copper wire shape and get a full-size printable template plus a step-by-step bend list (also SVG and DXF downloads).
