Share the memoir

Makes one file with every story — the recordings and the written versions — sorted into chapters. It opens in any web browser on a phone or computer, and prints nicely without the players.

Daily reminder

Adds a repeating event to your iPhone Calendar that reminds you each day. Tap Add All when the Calendar asks.

Back up your stories

Your stories are stored only on this phone, in this app. Back up now and then (save the file to iCloud Drive or Dropbox) so nothing is lost if the phone is replaced.

Live written version (experimental)

Uses the phone's own speech recognition. It may not work on every phone, and you can always type or fix the written version yourself.

Install on your Home Screen

In Safari, tap the Share button, then Add to Home Screen. It then opens like a regular app, and iOS is much less likely to clear its storage.
