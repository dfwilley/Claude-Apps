Get the files

For the Pico

Three files that go on the Pico next to Waveshare's driver. The Pico moves the sun's dot to the right day by itself.

How to set up the Pico
  1. Put MicroPython on the Pico (hold BOOTSEL, plug in, drag the .uf2 file from micropython.org onto it).
  2. From Waveshare's Pico_ePaper_Code on GitHub, folder python, take the file for the 7.5 inch panel and save it on the Pico as epd.py.
  3. In Thonny, save analemma.bin, analemma_data.py and main.py from this page onto the Pico.
  4. On a Pico W, open main.py and type your Wi-Fi name and password at the top so it can get the date. On a plain Pico, start it from Thonny once, which sets its clock.
  5. Press Run (or unplug and plug in). The panel refreshes once a day.

Other ways

The PNG is the picture as you see it. The BMP and C header are already turned to 800 × 480 for the panel; the C header suits Arduino or ESP32 code. The CSV lists the sun for every day, with distances in your units for a wall or floor mark.

Everything is worked out on this device; nothing is sent anywhere. Sun positions use NOAA's formulas and are good to a small fraction of a degree.
