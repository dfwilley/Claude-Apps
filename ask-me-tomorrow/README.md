# Ask Me Tomorrow

One question a day about your life. Answer it out loud, and over time the answers become a memoir for your family, sorted into chapters.

**Open it on your iPhone:** https://dfwilley.github.io/Ask-Me-Tomorrow/
(In Safari, tap Share › **Add to Home Screen** so it opens like an app.)

## What it does

- **Today:** one question a day (172 built-in questions in 14 chapters, plus your own). Tap the big red button and talk; pause if you need to; listen back; save. "Ask me later" puts a question off for two weeks; "Not for me" skips it for good.
- **Memoir:** every story by chapter, with the recording and an optional written version. Add more to a story, save a single recording to send to someone, or delete one.
- **Questions:** browse every question, answer any of them now, and add your own (or ones family suggest). Your own questions are asked first.
- **Book:** set the book title, storyteller and dedication, then **Make the memoir book**: one HTML file with every recording and written version that opens in any web browser and prints cleanly. Also a daily Calendar reminder, backup and restore, and an optional live written version using the phone's speech recognition.

## Privacy

Recordings and settings stay on the phone, in the browser's storage for this site. Nothing is uploaded. Make a backup now and then (Book › Back up everything) and keep the file in iCloud Drive or Dropbox.

## Files

- `index.html`, `style.css`, `app.js`: the app
- `questions.js`: the question bank — edit it to add or change built-in questions
- `reminders/`: ready-made daily Calendar reminders, one per half hour
- `sw.js`, `manifest.webmanifest`, `icons/`: Home Screen and offline support
